# Definition of Done — Payment Provider

A payment provider is finished only when the R.I.C.H.O. evidence record proves: verified merchant account; verified payout/settlement path; sandbox and live secrets separated; signed webhook validation; duplicate suppression; successful fixed-price A$199 sandbox flow; safe failed-payment handling; normalized fulfilment exactly once; healthy production deployment; owner emergency-disable; and one supervised/reconciled live transaction.

Anything less remains incomplete, blocked, or owner-input-required.
